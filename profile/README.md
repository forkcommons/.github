## Fork Commons

Free, open-source replacements for software that private-equity roll-ups are squeezing.

When a useful product gets bought, its staff cut, its prices raised and its features removed, the people who depend on it deserve a way out. Fork Commons builds and hosts that way out:

- **Free software**, under licenses that keep it free.
- **Easy to leave to**: importers that bring your data with you.
- **Hosted for you**, or run it yourself. Supported by donations and an at-cost cloud.
- **Built so it can't be bought**: the code, name and mission are being set up under nonprofit stewardship, never for sale.

We work with existing open-source projects first and build only where nothing exists.

Early days. More soon at [forkcommons.org](https://forkcommons.org).
